## README — explicação de 5 a 10 linhas
O projeto implementa um sistema simples de cadastro de participantes de um evento geek. A classe `Participante` guarda o identificador, nome, e-mail e tipo de participação. Seus atributos são privados e podem ser acessados por getters e setters. As classes `ParticipanteCampeonato`, `ParticipanteCosplay` e `ParticipantePalestra` herdam da classe principal e possuem dados próprios. O método `exibirDados()` mostra os dados comuns e os dados específicos de cada participante. A classe `Main` cria três objetos diferentes e os exibe no console. O projeto aplica encapsulamento, herança e polimorfismo. A execução deve ser testada com o JDK instalado.
