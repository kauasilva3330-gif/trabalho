# Desafio POO I — Operação Crachá Geek

Projeto Java para cadastrar e exibir participantes de um evento geek.

## Implementado
- Classe `Participante` com atributos privados, getters/setters e validações.
- Encapsulamento, herança e polimorfismo.
- Classes especializadas: `ParticipanteCampeonato`, `ParticipanteCosplay` e `ParticipantePalestra`.
- Classe `Main` que cria e exibe três participantes no console.

## Como executar
Com o JDK instalado, na pasta do projeto:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

## Desenho manuscrito obrigatório
A atividade também pede um desenho feito à mão da classe `Participante`, com atributos privados e métodos, além das três classes derivadas e suas relações de herança. Faça o desenho em uma folha, fotografe/digitalize e entregue junto com o link deste repositório.
